# Bank Widget

Проект для отображения последних успешных банковских операций клиента.

## Установка

1. Установите Poetry.
2. Клонируйте репозиторий.
3. Установите зависимости:
   ```bash
   poetry install

## Главный модуль
В модуле `src.main` реализован пользовательский интерфейс для фильтрации и вывода транзакций. Запуск: `poetry run python -m src.main`.
